# Biome Atmosphere (NeoForge 1.21.1, только клиент)

Оригинальный лёгкий мод:
- туман по биому, времени суток и погоде;
- оттенок неба и воды по биомам;
- частицы в воздухе (пыльца, пыль, песок, снег, светлячки, споры, лепестки);
- мягкая цветокоррекция;
- свет от предметов в руках (факел, фонарь, глоустоун, лава и любые светящиеся блоки).
  Модель предмета в руке освещается этим светом, так что факел в руке тоже "горит".

## Как получить jar (без установки Java и Gradle)
1. Создай репозиторий на github.com и загрузи в него все файлы проекта (вместе с папкой `.github`).
2. Открой вкладку **Actions** -> **build** -> дождись зелёной галочки (2-5 минут).
3. Внутри запуска скачай артефакт **biomeatmosphere-jar**, в нём лежит `biomeatmosphere-1.0.0.jar`.

## Как получить jar локально
Нужны Java 21 и Gradle 8.8+ (или скопируй gradlew и папку gradle из
https://github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle).
Команда: `gradle build` (или `./gradlew build`). Мод будет в `build/libs/`.
Если Gradle не находит `neo_version=21.1.172`, поставь любую 21.1.x в `gradle.properties`.

## Как играть
1. Установи NeoForge 1.21.1 (лаунчер или установщик с neoforged.net).
2. Положи jar в папку `mods`. Больше ничего не нужно (Sodium и другие моды не обязательны).
3. Настройки: Mods -> Biome Atmosphere -> Config, файл `config/biomeatmosphere-client.toml`.
   Каждую фичу можно выключить и регулировать силу.

## Известные ограничения
- Цветокоррекция это полупрозрачный оттенок поверх экрана (по F1 скрывается вместе с HUD).
  Настоящая кривая насыщенности и контраста требует шейдеров.
- Оттенок неба делает один миксин (`ClientLevelMixin`). Если не сработал, мод не падает, просто без неба.
- С Sodium/Embeddium оттенок воды может не примениться (не проверялось).
- Свет из руки: ставится невидимый клиентский блок Light у головы (сервер о нём не знает, в мир он
  не сохраняется). Под водой (голова и ноги в воде) света нет. Свет других игроков не показывается.
  При ходьбе пересчитывается освещение рядом, это небольшая нагрузка.
- Код не компилировался на момент написания: если сборка выдаст ошибку, пришли лог.
